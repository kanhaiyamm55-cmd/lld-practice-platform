# START HERE — LLD Coach

## If you only want to see the product
Open `demo.html` directly in Chrome/Edge. It is a self-contained working demo with localStorage, practice, evaluation, feedback and history. No Node.js or installation is required.

## If you want the full engineering project
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run install:all
npm run dev
```

5. Open http://localhost:5173

## Windows shortcut
Double-click `start-windows.bat`. It checks Node/npm and starts the full app after dependencies are installed.

## What to submit
Use the full source project for the assignment. `demo.html` is only a zero-setup showcase/fallback.
